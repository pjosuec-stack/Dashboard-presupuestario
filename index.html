Conexión con Google Drive

Configure una vez el ID de cliente de Google. Después pulse «Conectar Google Drive»: la última cédula se cargará al autorizar la conexión.



Pasos para publicar y conectar
  1. Suba este archivo al repositorio como index.html. En GitHub: Settings → Pages → Deploy from a branch → seleccione la rama y / (root). Abra la dirección HTTPS publicada.
  2. En Google Cloud, cree o seleccione un proyecto y habilite Google Drive API.
  3. Configure Google Auth Platform: Branding, Audience y Data Access. Añada el permiso https://www.googleapis.com/auth/drive.readonly. Para uso personal externo en modo Testing, añada su correo a Test users; para una cuenta institucional use Internal si está disponible.
  4. En Clients cree un cliente OAuth de tipo Web application. Añada como Authorized JavaScript origins el origen que aparece debajo, sin la ruta del repositorio. No necesita un secreto de cliente ni una clave API.
  5. Copie el Client ID aquí y guarde. Pulse «Conectar Google Drive» y seleccione la cuenta con acceso a la carpeta.

Origen que debe autorizar:

La conexión consulta únicamente archivos CSV y Excel de la carpeta de cédulas; el permiso de Google permite lectura de Drive. Cada visitante necesita una cuenta autorizada y acceso a la carpeta. Google puede solicitar nuevamente conexión al abrir otra sesión o cuando expire la autorización. La configuración se guarda en este navegador; las credenciales de acceso y los datos no se guardan en el repositorio.

«Más reciente» significa fecha de creación en Drive, no la fecha escrita en el nombre. No se consultan subcarpetas. Se mantiene el CSV original delimitado por punto y coma y se lee la primera hoja de Excel.

Si aparece origin_mismatch, revise el origen autorizado. Si aparece access_denied, revise los usuarios de prueba o las políticas de su institución. Si la API devuelve 403, compruebe que Google Drive API esté habilitada y que la cuenta tenga acceso a la carpeta.
